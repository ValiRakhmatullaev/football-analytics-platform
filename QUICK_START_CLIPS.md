# 🎬 Быстрый старт: Нарезка видео на клипы

## ✅ Что нужно сделать

### 1. Применить миграцию

```bash
cd backend
python manage.py migrate analytics
```

### 2. Настроить FFmpeg (если нужно)

Если ваш ffmpeg по пути `/Users/valijonrakhmatullaev/PyCharmMiscProject/ffmpeg_bin/ffmpeg`, 
добавьте в `backend/config/settings/base.py`:

```python
FFMPEG_PATH = "/Users/valijonrakhmatullaev/PyCharmMiscProject/ffmpeg_bin/ffmpeg"
```

### 3. Загрузить видео

1. Откройте `http://127.0.0.1:3000/upload`
2. Выберите видео файл
3. Отметьте "Create match automatically"
4. Введите названия команд
5. Нажмите "Upload & Process Video"

### 4. Дождаться обработки

Система автоматически:
- ✅ Обработает видео
- ✅ Детектирует события
- ✅ **Создаст клипы с важными моментами**
- ✅ Сгенерирует миниатюры

### 5. Просмотреть клипы

После обработки:
- Нажмите кнопку **"🎬 Просмотреть клипы"** в форме
- Или откройте: `http://127.0.0.1:3000/videos/<video_id>/clips`

## 🎯 Что создается автоматически

При обработке видео система создает клипы для:

- ⚽ **Голы** - удары с высокой уверенностью
- 🎯 **Удары** - удары по воротам
- ⚠️ **Опасные моменты** - ключевые ситуации
- 📤 **Ключевые пасы** - важные передачи

Каждый клип включает:
- Несколько секунд до события (контекст)
- Несколько секунд после события (результат)
- Миниатюру для быстрого просмотра

## 📊 Где посмотреть

### Через веб-интерфейс:
```
http://127.0.0.1:3000/videos/<video_id>/clips
```

### Через API:
```bash
# Все клипы
GET http://127.0.0.1:8000/api/analytics/videos/<video_id>/clips/

# Только голы
GET http://127.0.0.1:8000/api/analytics/videos/<video_id>/clips/?type=goal
```

## 🔍 Проверка работы

После обработки видео выполните:

```bash
python check_analytics.py
```

Скрипт покажет:
- Количество созданных клипов
- Ссылку на просмотр клипов
- Информацию о каждом клипе

## ⚠️ Важно

1. **FFmpeg обязателен** - без него клипы не создадутся
2. **Обработка может занять время** - особенно для длинных видео
3. **Клипы создаются только для важных моментов** - с достаточной уверенностью детекции

## 🎉 Готово!

После применения миграции система готова к работе. Просто загрузите видео и клипы создадутся автоматически!

# Улучшения системы детекции и нарезки видео

## 🔧 Используемые технологии

### Computer Vision (CV)
**Да, используется OpenCV (cv2)** - это библиотека компьютерного зрения.

**Что делается с CV:**
1. **Детекция мяча** (`event_detector.py`):
   - Использует цветовую сегментацию в HSV пространстве
   - Морфологические операции для очистки маски
   - Поиск контуров и фильтрация по размеру/форме
   - Определение центра и уверенности детекции

2. **Детекция движения** (`detect_events_from_motion`):
   - Вычисление разницы между кадрами (frame differencing)
   - Пороговая обработка для выделения движения
   - Поиск областей движения

3. **Обработка видео** (`video_processor.py`):
   - Извлечение кадров из видео
   - Временная выборка (sampling)

## 🎯 Что было улучшено

### 1. Исправление ошибки EmptyRanges

**Проблема:** Ошибка "Can't find variable: EmptyRanges" в браузере.

**Решение:**
- Добавлен атрибут `playsInline` для мобильных устройств
- Улучшена обработка ошибок видео элемента
- Добавлен обработчик `onLoadedMetadata`
- Убраны потенциально проблемные атрибуты

### 2. Улучшение классификации клипов

**Проблема:** Все события классифицировались как "опасные моменты".

**Решение - новая логика классификации:**

#### Голы (Goals)
- **Условие:** `event_type == "shot"` AND `confidence >= 0.65` AND `y < 15%` OR `y > 85%` (близко к воротам)
- **Временное окно:** -6 сек до +12 сек (включая празднование)
- **Приоритет:** Высший

#### Удары (Shots)
- **Высокая уверенность (≥0.6):** "Shot on Goal" - окно -4/+6 сек
- **Средняя уверенность (≥0.45):** "Shot Attempt" - окно -3/+5 сек

#### Ключевые пасы (Key Passes)
- **Условие:** `event_type == "pass"` AND `confidence >= 0.55` AND `y < 40%` (атакующая половина)
- **Временное окно:** -2.5/+4 сек

#### Опасные моменты (Dangerous Moments)
- **Удары:** `confidence >= 0.35` AND `y < 20%` OR `y > 80%` (опасная зона)
- **Пасы:** `confidence >= 0.45` AND в опасной зоне
- **Временное окно:** -2/+4 сек

**Ключевое улучшение:** Теперь используется позиция события (x, y) для более точной классификации!

### 3. Оптимизация нарезки видео

**Улучшения FFmpeg команды:**
- Добавлен `-movflags +faststart` - быстрый старт воспроизведения
- Добавлен `-pix_fmt yuv420p` - совместимость с браузерами
- Улучшена точность: `-ss` перед `-i` для быстрого поиска
- Добавлен `-vsync cfr` - постоянная частота кадров
- Оптимизированы настройки качества (CRF 22 для medium)

**Временные окна:**
- Голы: -6/+12 сек (самое длинное - включает празднование)
- Удары: -4/+6 сек или -3/+5 сек
- Пасы: -2.5/+4 сек
- Опасные моменты: -2/+4 сек или -2/+3.5 сек

### 4. Улучшение детекции событий (CV)

**Что уже используется:**
- Множественные цветовые диапазоны для мяча (оранжевый, желтый, белый, черный)

## 📊 Логика работы

### Процесс обработки:

1. **Загрузка видео** → `VideoUpload` модель
2. **Обработка** → `VideoAnalyticsPipeline`:
   - Извлечение кадров (OpenCV)
   - Детекция событий (OpenCV + эвристики)
   - Экспорт в JSON
3. **Создание клипов** → `VideoClipper`:
   - Классификация событий по типу и позиции
   - Определение временных окон
   - Нарезка через FFmpeg
   - Генерация превью
4. **Сохранение** → `VideoClip` модель в БД

### Классификация клипов (новая логика):

```
Событие (shot/pass) + Confidence + Позиция (x, y)
    ↓
├─ Shot + Conf ≥ 0.65 + Near Goal → GOAL
├─ Shot + Conf ≥ 0.6 → SHOT (high)
├─ Shot + Conf ≥ 0.45 → SHOT (medium)
├─ Pass + Conf ≥ 0.55 + Attacking → KEY PASS
├─ Shot + Conf ≥ 0.35 + Dangerous Area → DANGEROUS MOMENT
└─ Pass + Conf ≥ 0.45 + Dangerous Area → DANGEROUS MOMENT
```

## 📝 Технические детали

**OpenCV используется для:**
- `cv2.cvtColor()` - конвертация цветовых пространств
- `cv2.inRange()` - цветовая сегментация
- `cv2.morphologyEx()` - морфологические операции
- `cv2.findContours()` - поиск контуров
- `cv2.absdiff()` - разница кадров
- `cv2.threshold()` - пороговая обработка

**FFmpeg используется для:**
- Нарезка видео сегментов
- Генерация превью (thumbnails)
- Оптимизация для веб-воспроизведения

# Статус проекта: Football Analytics Platform

## Цель проекта
Разработать аналитическую платформу, в которую можно загружать видеозаписи матчей, а система в ответ выдаёт детализированные аналитические показатели и инсайты.

---

## ✅ ЧТО УЖЕ РЕАЛИЗОВАНО

### 1. Backend (Django REST Framework)

#### ✅ Модели данных
- **Competitions**: Competition, Season, Match, MatchTeam
- **Teams**: Team
- **Players**: Player, Appearance
- **Events**: Event (pass, shot, turnover, recovery)
  - Поддержка координат (x, y), временных меток, confidence scores
  - Связи между событиями (related_event, secondary_player)

#### ✅ API Endpoints
- `GET /api/analytics/matches/` - Список матчей
- `GET /api/analytics/matches/<match_id>/overview/` - Обзор матча
- `GET /api/analytics/matches/<match_id>/players/<player_id>/profile/` - Профиль игрока
- `GET /api/analytics/coach-summary/` - Аналитика для тренера

#### ✅ Сервисы аналитики
- Player metrics (events per 90, etc.)
- Team metrics
- Match dashboard
- Coach summary (strengths, weaknesses, tactics, load)

#### ✅ Django Management Command
- `python manage.py process_video` - Обработка видео через командную строку

### 2. Frontend (Next.js + TypeScript)

#### ✅ Страницы
- Главная страница (`/`) - Список матчей
- Страница матча (`/matches/[matchId]`) - Обзор матча
- Профиль игрока (`/matches/[matchId]/players/[playerId]`) - Детальная аналитика игрока
- Coach Summary (`/teams/[teamId]/coach-summary`) - Аналитика для тренера

#### ✅ Компоненты
- PlayerHeader - Заголовок профиля игрока
- PerformanceSnapshot - Снимок производительности
- ExplainableInsightCard - Карточка инсайта
- DecisionSummary - Резюме решений
- MetricTrendList - Список трендов метрик

### 3. Video Analytics Pipeline

#### ✅ Модули обработки видео
- `video_processor.py` - Загрузка и обработка видео
- `event_detector.py` - Детекция событий (pass, shot, turnover, recovery)
- `pitch_calibration.py` - Калибровка координат поля
- `data_exporter.py` - Экспорт в Django-совместимый формат
- `pipeline.py` - Главный оркестратор

#### ✅ Функциональность
- Обработка видео (MP4, AVI и др.)
- Извлечение кадров с настраиваемой частотой
- Детекция мяча (цветовая)
- Детекция событий на основе движения мяча
- Экспорт в JSON и напрямую в Django БД
- Debug инструменты для визуализации

## ❌ ЧТО ОТСУТСТВУЕТ (Критично для MVP)

### 1. API для загрузки видео

**Проблема**: Нет endpoint для загрузки видео через веб-интерфейс.

**Нужно создать**:
- `POST /api/analytics/videos/upload/` - Загрузка видео файла
- `POST /api/analytics/videos/<video_id>/process/` - Запуск обработки видео
- `GET /api/analytics/videos/<video_id>/status/` - Статус обработки

### 2. Frontend: Компонент загрузки видео

**Проблема**: Нет UI для загрузки видео.

**Нужно создать**:
- Страница `/upload` или компонент на главной странице
- Drag & drop загрузка файлов
- Прогресс-бар обработки
- Отображение статуса обработки

### 3. Интеграция Video Analytics с Django API

**Проблема**: Video Analytics работает только через командную строку.

**Нужно создать**:
- Celery задачи для асинхронной обработки
- Модель VideoUpload для хранения метаданных
- Автоматический запуск pipeline после загрузки
- WebSocket/SSE для обновления статуса в реальном времени

### 4. Хранение видео файлов

**Проблема**: Нет системы хранения загруженных видео.

**Нужно создать**:
- Настройка MEDIA_ROOT и MEDIA_URL в Django
- Модель для хранения метаданных видео
- Обработка больших файлов (chunked upload)

### 5. Связь видео с матчем

**Проблема**: Нет способа связать загруженное видео с существующим матчем.

**Нужно создать**:
- UI для выбора матча при загрузке
- API для создания матча из видео
- Автоматическое определение периода (1-й/2-й тайм)

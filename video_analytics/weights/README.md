# Веса YOLO для детекции (опционально)

По умолчанию пайплайн **не** использует локальный файл из этой папки.

Чтобы использовать свою модель:
- Укажите путь к `.pt` в настройках Django: `ROBOFLOW_FOOTBALL_MODEL_PATH = "/путь/к/модели.pt"`
- Или в переменной окружения: `export ROBOFLOW_FOOTBALL_MODEL_PATH=/путь/к/модели.pt`
- Или передайте `--model /путь/к/модели.pt` при запуске `run_possession_pipeline.py`

Если путь не задан, используется базовая модель YOLOv8n (person + sports ball из COCO).

# Руководство по видео клипам (нарезкам)

## 🎬 Что было реализовано

### 1. Автоматическая нарезка видео
- ✅ При обработке видео автоматически создаются клипы с важными моментами
- ✅ Определяются: голы, удары, опасные моменты, ключевые пасы
- ✅ Каждый клип обрезается с контекстом (несколько секунд до и после события)

### 2. Модель данных
- ✅ `VideoClip` - хранит информацию о каждом клипе
- ✅ Связь с событиями и видео
- ✅ Метаданные: тип, длительность, таймстамп, уверенность

### 3. API Endpoints
- ✅ `GET /api/analytics/videos/<video_id>/clips/` - список всех клипов
- ✅ `GET /api/analytics/videos/<video_id>/clips/?type=goal` - фильтр по типу
- ✅ `GET /api/analytics/clips/<clip_id>/video/` - просмотр видео
- ✅ `GET /api/analytics/clips/<clip_id>/thumbnail/` - миниатюра

### 4. UI компонент
- ✅ `VideoClipsViewer` - компонент для просмотра клипов
- ✅ Страница `/videos/[videoId]/clips` - полная страница просмотра
- ✅ Фильтрация по типам
- ✅ Встроенный видеоплеер

## 🚀 Как использовать

### 1. Загрузить и обработать видео

При загрузке видео с автоматическим созданием матча:
- Видео обрабатывается
- События детектируются
- **Автоматически создаются клипы** с важными моментами

### 2. Просмотреть клипы

**Через веб-интерфейс:**
```
http://127.0.0.1:3000/videos/<video_id>/clips
```

**Через API:**
```bash
GET http://127.0.0.1:8000/api/analytics/videos/<video_id>/clips/
```

### 3. Фильтровать клипы

```bash
# Только голы
GET http://127.0.0.1:8000/api/analytics/videos/<video_id>/clips/?type=goal

# Только удары
GET http://127.0.0.1:8000/api/analytics/videos/<video_id>/clips/?type=shot
```

## 📋 Типы клипов

- **goal** - Голы (высокая уверенность ударов)
- **shot** - Удары по воротам
- **dangerous_moment** - Опасные моменты
- **pass** - Ключевые пасы
- **tackle** - Подкаты (будущее)
- **save** - Сейвы (будущее)

## ⚙️ Настройка

### FFmpeg путь

Если ffmpeg не в PATH, укажите путь в `settings.py`:

```python
FFMPEG_PATH = "/path/to/ffmpeg"
```

### Качество клипов

В `video_clipper.py` можно настроить качество:
- `quality="low"` - быстро, низкое качество
- `quality="medium"` - баланс (по умолчанию)
- `quality="high"` - медленно, высокое качество

### Длительность клипов

В `identify_important_moments()` настраиваются:
- `start_offset` - секунд до события
- `end_offset` - секунд после события

   ```bash

   ffmpeg -version
   
   # Если не установлен (macOS)
   brew install ffmpeg
   ```

2. **Применить миграцию**
   ```bash
   cd backend
   python manage.py migrate analytics
   ```

## 🎯 Пример использования

1. **Загрузить видео** через `/upload` с "Create match automatically"
2. **Дождаться обработки** (создание клипов происходит автоматически)
3. **Открыть клипы**:
   - Через веб: `/videos/<video_id>/clips`
   - Или получить `video_id` из статуса обработки
4. **Просмотреть клипы** - кликнуть на миниатюру для воспроизведения

## 📊 Статистика клипов

После обработки в ответе будет:
```json
{
  "clips_created": 5,
  "clips_url": "/api/analytics/videos/<id>/clips/"
}
```

## ⚠️ Важные замечания

1. **FFmpeg обязателен** - без него клипы не создадутся
2. **Обработка может занять время** - зависит от количества событий
3. **Клипы создаются только для важных моментов** - с достаточной уверенностью
4. **Клипы сохраняются на диск** - могут занимать место

## 🐛 Troubleshooting

### Клипы не создаются

1. Проверить наличие ffmpeg:
   ```bash
   which ffmpeg
   ```

2. Проверить логи обработки - ошибки будут в логах Django

3. Проверить события - если событий 0, клипов не будет

### Ошибка "ffmpeg not found"

Укажите путь в `settings.py`:
```python
FFMPEG_PATH = "/Users/valijonrakhmatullaev/PyCharmMiscProject/ffmpeg_bin/ffmpeg"
```

### Клипы создаются, но не отображаются

1. Проверить права доступа к файлам
2. Проверить MEDIA_URL в settings
3. Проверить, что файлы существуют на диске
